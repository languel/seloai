## 1.1 World authoring and the patchwork (merged)

The full design and every setting is in [docs/WORLD_EDITOR_PLAN.md](docs/WORLD_EDITOR_PLAN.md); this is the map.

- **Worlds are scenes.** A world is a recipe (generator, parameters, seed) plus hand edits (`src/world/worldScene.ts`). `bakeScene` runs it (cached per scene), `mapFromScene` derives walkability, landmarks and spawns. Every change is a `scene.edit` command through `WorldStore` (`src/world/commands.ts` validates each op). Generators: valley (Wang), patchwork village, Zmeyovo, Shevitsa (`src/world/sceneGenerators.ts`).
- **Patchwork village** (`src/world/patchworkVillage.ts`, art in `src/art/patchworkArt.ts`): an irregular quad grid (`src/art/irregularGrid.ts`) filled by a collapse fill; plots are drawn in from the streets, a continuous river with plank bridges, named buildings near the square, animals. Plots keep their raw face and street widths so they can be merged and split.
- **World Editor** (`src/components/WorldEditorView.tsx`, tab `world`): layers as in a tile map (ground, patterns, plantings, works, buildings, animals; hide, lock, active layer), select and move, rotate (`[` `]`), paint (terrain, or plot kind, merge, split in a patchwork), place (a palette per layer, including building kinds), scatter (medallions go on a lattice), the pattern brush (strokes, fills, fill a plot), an erase brush, landmarks and spawns, and an edit list that survives reseeding.
- **World settings** (left panel): threads (`WORLD_PALETTES` in `src/art/looks.ts`; figures and overlays follow via `clothPalette`), house look (drawn, stitched upright, stitched along the streets), house size, layout (overlapping or packed), and legibility (backdrop strength, quiet paths).
- **Figures** (`src/art/figures.ts`, `src/art/gameLook.ts`): arms down by default (`stance: 'everyday'`), swinging when walking, gesturing when talking; raised only to dance (an activity that names a dance or celebration, or standing still on a dancing ground).
- **Textile village** (`src/world/textileVillage.ts`, layouts in `src/art/textileLayouts.ts`, operators in `src/art/compose.ts`, signs in `src/art/textileLexicon.ts`): a village laid out as one piece of counted work, a carpet or a sampler, with about a tenth of the cloth worked. The owner's current direction for composition; see section 6.2 of the art direction doc. Lab: `/art-lab.html?only=compose`.
- **Known gaps**: big houses are drawn past their footprints, so people can cross the overhang; packed layout measures bounding boxes, so it leaves more linen than a stitcher would; the old Level Editor and Tapestry Studio tabs (`level`, `tapestry`) are still present and should be retired; characters' portraits keep their signature pose.
- **Next, proposed to the owner**: a composable pattern system in the Pattern Studio (radial snowflake compositions, branching tree-of-life compositions, interwoven crossings), whose results become references usable by the palette, the pattern brush and medallions. Then: Loom pass two, the pattern cell editor and library, retiring the old editors.

## 1.2 Agents and Spinner (branch `pi-agent`, merged; latest work)

- **State:** an agent can build a world from nothing with a person, change any style or setting, edit looks from plain words, drive the interface, draw, narrate, run a scripted performance and record it. Tested: headless tests for every tool family, a live Qwen 3.8 9B (Ollama) run that built a whole world, and scripted walkthroughs in the app.
- **Not yet tested:** recording the whole app tab (needs the person's click), a model writing a long walkthrough on its own, and the local LFM3-1.7B on multi-step requests (small models over-reach: the panel shows what really changed under each tool step).
- **Not built:** recording a person's own clicks and drags as a replayable script; Spinner as an embeddable script for other pages; MCP over HTTP; Gemini tool calling.
- **Live model test:** `PI_LIVE_MODEL=<ollama model> pnpm exec vitest run src/agent/__tests__/piLive.test.ts`.
- **Known flaky:** `src/api/__tests__/tools.test.ts` (spawns the MCP server) times out under the full suite; it passes alone.

## 3. Running, Testing & Deploying

- **Dev server**: `pnpm dev -- --port 5173`
- **Asset generator (optional regen)**: `node --experimental-strip-types scripts/generateBalkanMythAssets.mjs`
- **Typecheck & unit tests**: `pnpm exec tsc --noEmit && pnpm test` (`vitest run` across the `__tests__` folders under `src/engine`, `src/ai`, `src/api`, `src/storage` and `src/utils`); lint with `pnpm lint`
- **Production build**: `pnpm build` (`tsc -b && vite build`; GitHub Pages uses `VITE_BASE_PATH="/<repo>/"`)
- **Auto-Deploy on Push to `main` (GitHub Pages CI)**: `.github/workflows/deploy-pages.yml` triggers automatically on every push to `main` (and `workflow_dispatch`), runs `pnpm install --frozen-lockfile`, `pnpm exec tsc --noEmit`, `pnpm test`, builds `dist/` with `VITE_BASE_PATH="/<repo>/"`, uploads via `actions/upload-pages-artifact@v3`, and publishes via `actions/deploy-pages@v4` to `https://languel.github.io/seloai/`.
  - Repository **Settings → Pages → Source** must remain **GitHub Actions** (`build_type: workflow`).

## 4. Browser Verification Checklist

1. Open the app in WebGPU-capable Chrome/Edge (`http://localhost:5173/` or `https://languel.github.io/seloai/`).
2. In **Village**, verify **Zmeyovo: Well of the Lamia** (`public/assets/balkan-myth-tileset.png` + `public/assets/spritesheets/balkan/*.png`) loads cleanly, switch worlds via the header **Demo & Saved Worlds** dropdown, test the signed log rewind/speed slider (`-10× .. +10×`), eased zoom, `@`/`#` autocomplete composer with bold entity chips, and open **Style** (**Appearance & Player Studio**) to adjust menus/bubble glass themes, font/text scale, label de-overlap, character scale, and the procedural world-matched player sprite.
3. In **Level Editor**, verify the **Wang Auto-Tile** brush tool paints seamless transitions across rows `12..15` (`balkan-myth-tileset.png`) and saves custom stamps/POIs.
4. In **Tapestry Studio**, test pinch-zoom / two-finger pan, run **AI Auto-Slicer** (`Smart Contrast`, `EdgeTAM` WebGPU, or **SAM Click** point-to-segment) on closed-outline motif maps, paint with the **Sample** palette brush, stage aspect-preserved motifs directly or drag from **Pattern Library** into non-overlapping output tiles in **Preview Output**, reposition/resize with the 8-handle box (Shift aspect lock, snap), and verify **Apply to Map** / **Apply & Place**.
5. In **AI & Voice Monitor**, optionally load a WebGPU model (`LFM3-Omni-2B` default or `LFM3-1.7B`) or connect Ollama/LM Studio/External APIs, test mic STT + 24 kHz TTS, and verify **Flush Audio** cancels queued speech cleanly.
6. In **World & Data** (`Database` icon), verify **Saved Worlds in Memory**, **Whole Project**, **Level Only**, **Characters Only**, **Characters + Histories**, and **Database Only** export/import round-trips.
